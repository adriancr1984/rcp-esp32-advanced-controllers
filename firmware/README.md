# Firmware — ESP32-S3 integration layer

This folder holds the Arduino/ESP32-S3 integration layer that wraps the C/C++ code
generated by MATLAB Embedded Coder and runs it as a deterministic FreeRTOS task.

## Files

- `main.ino` — `extern "C"` wrapper + FreeRTOS control task + hardware mapping.
  The **controller-specific adapter block** at the top of `main.ino` is the only part
  that changes between controllers (PID / STSMC / MRAC): point it to the generated
  model header and to its input/output port names.
- The generated model files (`*.c`, `*.h`) are **not** included here (MathWorks
  academic-use license). Regenerate them from the Simulink models in `../simulink/`
  using the code-generation settings in the top-level `README.md`, then copy them
  into this folder before compiling.

## Pin mapping (ESP32-S3)

| Signal | ESP32-S3 GPIO | Connects to | Notes |
| :-- | :-- | :-- | :-- |
| Encoder channel A | GPIO 15 | Encoder A | `INPUT_PULLUP`, interrupt on CHANGE |
| Encoder channel B | GPIO 16 | Encoder B | `INPUT_PULLUP`, read for direction |
| PWM (speed) | GPIO 4 | L298N ENA | LEDC, 20 kHz, 10-bit |
| Direction 1 | GPIO 5 | L298N IN1 | digital |
| Direction 2 | GPIO 6 | L298N IN2 | digital |
| Telemetry UART | USB (CDC) | Host PC | 921600 bps |

> Adjust the GPIO numbers if your wiring differs; these are the pins used in the
> reported experiments.

## Signal conditioning / actuation

- **Position**: decoded in software from a pin-change interrupt on channel A, using
  channel B for direction. Encoder: 4096 CPR quadrature.
- **PWM**: ESP32-S3 **LEDC** peripheral at **20 kHz, 10-bit** (`MAX_PWM = 1023`).
  10-bit is the maximum usable resolution at 20 kHz on the LEDC clock.
- **Actuator**: L298N driver limited to a **±6 V** range.
- The control command sign selects direction (IN1/IN2); its magnitude sets the PWM
  duty cycle.

## Build & flash (Arduino IDE)

1. Install the **ESP32 board package** (Espressif core, v3.x — this sketch uses the
   v3.x LEDC/timer API: `ledcAttach`, `timerBegin(freq)`, `timerAlarm`).
2. Select an **ESP32-S3** board and the correct COM port.
3. Copy the generated `*.c/*.h` for the desired controller into this folder and
   update the adapter block in `main.ino`.
4. Compile and upload.
5. Run the host tool `../telemetry/serial_logger.py` to drive the step reference and
   log the run.

## Real-time architecture

- A hardware timer fires at **1 kHz** and releases a binary semaphore.
- A dedicated FreeRTOS task (**priority 24, pinned to Core 1**) runs the controller
  `step()` and updates the actuator; telemetry runs on Core 0.
